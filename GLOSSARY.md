# Календарь звонков

Сервис бронирования календаря: один владелец публикует доступное время,
гость занимает слот и оставляет имя с email. Авторизации и базы данных нет —
весь словарь ниже описывает этот единственный контекст.

## Language

**Владелец**:
Единственный человек, чей календарь публикуется; задан заранее, без входа в систему.
_Avoid_: пользователь, админ, аккаунт

**Гость**:
Человек, который выбирает слот и оставляет имя и email при бронировании.
_Avoid_: клиент, посетитель, пользователь

**Тип встречи**:
Шаблон встречи — заданный владельцем `id`, название, описание и длительность; длительность задаёт размер слота.
_Avoid_: услуга, событие, ивент, встреча

**Слот**:
Интервал-кандидат на сетке дня со статусом «свободно» или «занято»; сам по себе ещё не бронь.
_Avoid_: ячейка, время, таймслот

**Сетка слотов**:
Старты дня: с 09:00 до 18:00 по Москве с шагом 30 минут, при этом встреча должна закончиться до 18:00.
_Avoid_: расписание, график

**Окно записи**:
Четырнадцать календарных дней по Москве, начиная с сегодняшнего; за его границами бронировать нельзя.
_Avoid_: горизонт, период, диапазон

**Бронь**:
Занятый интервал с данными гостя; единственный способ занять слот.
_Avoid_: запись, резерв, событие, appointment

**Занят** (`taken`):
Статус слота, если с ним пересекается хотя бы одна бронь.
_Avoid_: зарезервирован, недоступен

**Конфликт**:
Пересечение двух интервалов: `a.start < b.end && b.start < a.end`.
Касание границами конфликтом не считается.
_Avoid_: наложение, коллизия, двойная запись

**Предстоящее событие**:
Бронь со стартом не раньше текущего момента; так называется раздел владельца.
_Avoid_: запись, будущая встреча, upcoming

**Главная страница**:
Точка входа гостя: приветствие, карточка типа встречи и кнопка «Записаться».
_Avoid_: лендинг, домашняя страница, стартовая страница
